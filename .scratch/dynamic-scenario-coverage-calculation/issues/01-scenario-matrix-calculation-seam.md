# 01 — 建立场景矩阵计算接缝

**What to build:** 让一个场景的原始输入能够经过场景矩阵应用接缝，由自由空间路损模型生成覆盖距离或模型诊断，并让页面现有场景使用这条计算路径。计算结果与可编辑输入分离；Tabulator 不承载计算规则。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 建立场景独立的输入状态、派生结果和诊断状态边界，场景使用稳定 ID，名称不作为身份。
- [ ] 建立可注册的路损模型接缝，第一版注册自由空间路损模型，并支持正向路损计算与路损反解。
- [ ] 对自由空间模型使用 GHz、dB、km 单位；根据载波频率和总路损值反解覆盖距离。
- [ ] 非空路损值必须大于 0，载波频率必须大于 0；空输入返回缺少输入诊断，不显示过期结果。
- [ ] 输入按原始文本保留，具体模型负责解析、领域校验和结构化诊断。
- [ ] 默认输入为自由空间路损模型、2.4 GHz 和 100.1 dB 总路损值，覆盖距离约为 1 km。
- [ ] 页面首次加载时能够通过该接缝得到默认场景的覆盖距离；一个场景的诊断不阻塞其他场景。
- [ ] 建立能够验证该场景接缝外部行为的最小测试基础设施，覆盖有效计算、空值、非正数、过期结果和模型诊断。
