# 02 — 重构输入/输出参数矩阵

**What to build:** 将计算接缝呈现为最终的链路预算矩阵：用户看到独立场景列、固定参数名称、左侧分组栏、上方输入区和底部只读计算结果，并能直接编辑输入后看到覆盖距离更新。

**Blocked by:** 01 — 建立场景矩阵计算接缝

**Status:** ready-for-agent

- [ ] 表格内只保留最左侧固定的参数名称列，单位并入参数名称；不再显示独立单位列。
- [ ] 分组名称显示在表格左侧独立分组栏，不占用参数数据行；分组栏和参数名称列在场景横向滚动时固定。
- [ ] 保留当前原型的链路预算输入参数，加入路损模型和路损值，移除环境附加损耗和静态评估；将原链路距离改为覆盖距离结果。
- [ ] 输入参数位于上方，底部独立显示覆盖距离；输入与结果之间用清晰分割线区分。
- [ ] 路损模型使用下拉选择，第一版显示自由空间路损模型；路损值为可编辑总路损输入。
- [ ] 除参数名称、分组栏和计算结果外，场景输入单元格均可编辑；输入单击选中，双击进入文本编辑，回车或失焦提交，Esc 取消。
- [ ] 页面首次加载时显示各现有场景的计算结果；输入提交后只重新计算对应场景。
- [ ] 覆盖距离单元格只读并显示两位小数；无效输入时显示模型诊断而不是旧结果，并标记相关输入单元格。
- [ ] 其他保留的链路预算参数继续可编辑；自由空间模型暂时可以不使用它们，环境附加损耗不出现在第一版。
- [ ] 分组使用统一浅色背景和较粗分隔线；场景较多时保持场景列可读并允许横向滚动。
- [ ] 通过场景矩阵接缝验证默认计算、输入编辑、结果只读、错误替换和分组布局等外部行为。
