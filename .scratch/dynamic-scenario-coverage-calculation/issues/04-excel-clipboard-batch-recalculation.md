# 04 — 实现 Excel 复制粘贴与批量重算

**What to build:** 让用户能够在动态场景矩阵中安全地复制输入和结果到 Excel，并从 Excel 粘贴输入；只读内容不能被覆盖，整块输入完成后按受影响场景统一重算。

**Blocked by:** 02 — 重构输入/输出参数矩阵

**Status:** ready-for-agent

- [ ] 复制选区使用纯文本 Tab/换行格式；只读参数名称和覆盖距离可以复制，左侧分组名称不参与复制。
- [ ] 复制场景标题时使用最新的场景名称；只有明确选中列标题时才在正文前加入表头。
- [ ] 粘贴起始选中单元格必须是可编辑场景输入单元格；从参数名称列或只读结果位置开始时，整次粘贴不执行。
- [ ] 不自动识别或跳过 Excel 表头；合法起点后的数据按二维区域位置映射。
- [ ] 粘贴范围中的只读参数名称或覆盖距离位置跳过，不修改结果；超出当前矩阵范围的数据忽略。
- [ ] 输入值按原始文本写入，整块粘贴完成后对受影响场景各计算一次，而不是逐单元格刷新。
- [ ] 粘贴产生无效输入时显示对应模型诊断、标记相关输入，并清除过期覆盖距离。
- [ ] 覆盖单场景、多场景、动态新增场景、只读结果复制/跳过、非法起点、表头文本和越界数据等外部行为测试。
