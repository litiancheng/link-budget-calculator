# 固定报告矩阵并采用坐标式 TSV 交换

**Status**: superseded by ADR 0005

这份 ADR 记录最初的静态展示原型边界。后续决策已允许动态场景列和首个覆盖距离计算结果；其中关于固定四个场景列和“不含计算逻辑”的部分不再代表当前共识，TSV 交换的基本边界仍由后续 ADR 继承和细化。

最初版本将链路预算页面收敛为根页面直接呈现的唯一报告布局，保留原型现有参数行和四个场景列；参数名称、单位、分组标题和文本结果保持只读，只有普通参数行的场景值可编辑。网页与 Excel 之间使用纯文本 TSV 交换：复制正文选区时只输出选中的数据，只有用户点击或拖选列标题、明确选中整列时才在数据前加入对应表头；Excel 粘贴从选中范围的左上角直接按 Tab/换行填充，不识别表头；左上角不可编辑时取消整次粘贴，后续不可编辑位置跳过，超出矩阵范围的数据忽略。这些内容是早期静态原型的历史边界，当前的动态场景、可编辑输入和计算结果规则以 ADR 0004、ADR 0005 为准。

## Consequences

- 页面刷新后恢复默认示例内容。
- 场景列数量和参数行结构暂时固定，后续的动态增删需要单独设计。
- 粘贴操作简单可预测，但不会自动识别 Excel 表头，也不会替用户校验数据类型。
