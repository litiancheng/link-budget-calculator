# 采用可扩展的路损模型注册方式

**Status**: accepted

路损模型以可选择、可注册的领域模型存在，每个模型负责定义所需输入、路损计算和由给定路损反解覆盖距离；第一版只实现自由空间路损模型（FSPL），用户选择模型并填写模型参数，不直接输入任意公式。这样后续增加对数距离或其他标准模型时，可以扩展计算引擎而不改变场景状态和表格适配层。
第一版的最小计算合同是：每个场景输入载波频率和给定路损，FSPL 反解覆盖距离；界面单位约定为 GHz、dB 和 km。其他链路预算参数在界面中保留为可编辑输入，但暂不属于 FSPL 的最小计算合同。
第一版的给定路损语义是最大允许路损，覆盖距离是满足模型路损不超过该上限的最大距离。
第一版采用 `L(dB) = 92.45 + 20 × log10(f_GHz) + 20 × log10(d_km)`，并按 `d_km = 10^((L - 92.45 - 20 × log10(f_GHz)) / 20)` 反解覆盖距离。界面单位固定为 GHz、dB 和 km。
每个路损模型同时提供正向路损计算和路损反解能力；初期页面使用反解，正向能力用于模型验证、后续完整链路预算和其他结果展示。若模型没有解析反解，反解过程由模型内部处理，不能把求解细节暴露给 UI。
模型选择、载波频率、最大允许路损和其他模型参数都属于场景独立输入；项目只维护有序的场景集合，不把这些输入提升为项目级共享配置。
第一版新增场景直接使用固定默认模板并生成新的场景 ID，不提供从其他场景复制输入的操作。
默认模板使用 FSPL、2.4 GHz 和 100.1 dB 最大允许路损，默认名称为“新场景”，由模型反解得到约 1 km 的覆盖距离。
场景集合不设置最小数量限制；删除最后一个场景后集合为空，计算结果为空，其他场景不存在可受影响的数据。
新增场景入口固定在场景列集合的右上方：有场景时位于最后一个场景列的右侧；场景集合为空时位于第一列第一行。点击后创建使用默认模板的新场景。
