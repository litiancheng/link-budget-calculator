# 场景列采用轻量级标题操作

**Status**: accepted

场景以矩阵列呈现，第一版在每个场景标题旁直接提供小型 × 按钮。点击按钮立即删除对应场景列，允许删除最后一个场景；删除后保留参数矩阵和新增入口，但不再显示场景结果。

场景标题只显示场景名称，不显示频率、距离等副标题。场景标题支持双击编辑。双击后在标题位置显示单行文本输入框，Enter 或失焦提交，Esc 取消；空标题不提交。标题不是场景身份，重命名不改变场景 ID。

新增入口使用场景列集合右侧的 + 标题按钮；当场景集合为空时，+ 仍位于第一个可用场景列位置。新增场景使用固定默认模板，不复制其他场景。

这样可以让场景生命周期操作紧贴列本身，减少额外工具栏，同时保持参数行结构稳定，便于后续接入计算引擎。
