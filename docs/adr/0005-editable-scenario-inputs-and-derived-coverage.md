# 场景输入可编辑，覆盖距离作为派生结果

**Status**: accepted

## Decision

当前原型采用“参数名称列 + 场景列”的矩阵。只有最左侧参数名称列固定；单位并入参数名称显示。分组名称放在表格左侧独立的分组栏中，不占用参数数据行；分组栏和参数名称列在场景列横向滚动时保持固定。

场景列顶部只显示场景名称和删除按钮。场景名称双击后原位编辑，Enter 或失焦提交，Esc 取消，空名称不提交，允许重名。点击删除按钮立即删除场景，包括最后一个场景；场景集合为空时仍保留新增入口。新增场景使用固定默认模板，不从其他场景复制。

参数矩阵保留当前原型的链路预算参数，并增加路损模型和路损值输入，删除环境附加损耗和静态评估。输入区域位于上方，底部单独设置“计算结果”区域。第一版输出为覆盖距离，覆盖距离单元格只读并保留两位小数；后续可以在该区域增加其他只读结果。

路损模型使用下拉选择，第一版只有自由空间路损模型。路损值表示总路损，非空时必须大于 0；载波频率必须大于 0。自由空间模型第一版使用载波频率和总路损反解覆盖距离，不使用环境附加损耗；其他保留的链路预算参数仍可编辑，但当前模型暂不使用。

页面首次加载时使用默认输入计算。输入单元格在提交后重新计算对应场景；Excel 整块粘贴完成后，对受影响的场景各计算一次。场景输入保存为用户原始文本，具体模型负责解析、校验和生成结构化诊断。输入无效时，覆盖距离显示模型给出的简短错误信息并标记相关输入单元格，不显示过期结果。

计算引擎独立于 Vue 和 Tabulator。场景状态只保存输入，覆盖距离等结果由模型计算得到。模型可以在后续根据自身定义动态增加或隐藏输入参数行，并增加计算结果行。

只读参数名称列和计算结果可以复制到 Excel，但不能通过粘贴修改。粘贴起始选中单元格必须是可编辑输入单元格；粘贴范围中的只读结果位置跳过，超出范围的数据忽略；不自动识别或跳过表头，分组名称不参与复制。

## Consequences

- 计算结果不会与用户输入混存，避免显示过期结果或被粘贴覆盖。
- 当前 FSPL 模型的计算依赖范围很小，其他保留参数暂时修改后可能不改变覆盖距离；后续模型可以逐步接管这些参数。
- 参数行在原型阶段保持稳定，模型驱动的动态参数和结果行作为后续扩展点。
